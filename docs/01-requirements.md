# 01. Requirements

## 1. 项目背景

当前题库电子化需要耗费大量人工处理 PDF 文件中的题目、选项、答案和解析，尤其面对混合扫描件与原生文件的文档时，效率低下且容易出错。本项目旨在通过自动化手段与高效的人工校对界面，将原本手动的提取过程转变为“自动提取 + 人眼比对确认”的高效工作流。

## 2. 第一性原理与项目目标

**第一性原理**：可靠地定位题目、答案和解析在 PDF 页面中的空间边界，保留原始视觉内容，并把唯一必须机器可读的答案字段结构化。

**项目目标**：交付一个可安装运行的 Windows 桌面应用「PDF 题库自动提取工具」，提供单机、离线、高精度的 PDF 题库提取能力。提取结果支持导出 SQLite/JSONL/PNG，校对效率高。

## 3. 目标用户

单人单机的校对人员。无需账户体系、权限分配或多人协作功能。

## 4. 核心使用场景

1. **导入与解析**：用户将 PDF 题库与解析文件（若有）导入软件，系统根据单页属性（原生/扫描）自动分流至文本解析或 OCR 管线进行边界识别和数据提取。
2. **人工校对 (Review)**：用户在工作台中并排对照“原PDF页面”和“提取出的图片及答案”，快速修改错误、重划区域并一键保存，人工确认结果神圣不可侵犯。
3. **分档导出**：完成整本确认后，一键导出为结构化的 JSONL、SQLite 和独立切图的 PNG 文件。

## 5. MVP 范围

**本阶段必须完成**：
- 支持原生文本 PDF (Native) 和 扫描件 PDF (OCR) 的混合处理，页级别自动判定。
- OCR 作为并列主路径，需配置自动预处理流水线（灰度、纠偏、二值化、缩放）。
- 单项/多项选择题的题号、截图区域（必须包含图形和表格）、正确答案结构化和解析截图。
- 基于 PySide6 的桌面人工复核工作台（含快捷键，支持重划区域和手动修正）。
- 输出 SQLite、JSONL 及 PNG 图片包。
- 纯本地离线运行（模型放入 `models/`），支持断点续跑和幂等重试。

**本阶段明确不开发**：
- 双栏阅读顺序还原（本期仅做单栏，疑似双栏页报 WARNING 转人工 Review）。
- 在线视觉大模型或云端 OCR。
- 主观题、计算题等答案文本的结构化。
- 表格或公式的结构化（直接截图）。
- 按题号自动关联独立的题目PDF和答案PDF（分别导入）。
- 跨任务题目去重及相似题合并。
- 人工修图功能（遮盖、旋转、去噪）。

## 6. 功能列表

| 编号 | 功能 | 优先级 | 说明 |
| --- | --- | --- | --- |
| R-001 | 混合版面解析（Native+OCR） | P0 | 按页判断来源并使用 TextBlock 或 RapidOCR |
| R-002 | 区域规划与边界合并 | P0 | 题目区域必须包裹文本及非文本对象（图片/表格） |
| R-003 | 答案文本结构化 | P0 | 将提取的答案字符串归一化（如 'A', 'B'） |
| R-004 | PySide6 桌面端 Review 工作台 | P0 | 三栏布局，左列表/中原图对比/右属性修改，全键盘操作 |
| R-005 | 单页失败隔离与断点续跑 | P0 | 某页崩溃仅标记为 failed，整本任务可暂停恢复 |
| R-006 | 结构化导出与数据落盘 | P0 | 本地 SQLite WAL，导出 JSONL/PNG，防 manual_edit 覆盖 |

## 7. 用户流程

```text
启动应用检查环境 (模型/AVX2) -> 创建任务 (拖入PDF, 选择规则) -> 
后台并发按页处理 (预检 -> Native/OCR -> 边界合并 -> 数据入库) -> 
人工 Review (三态筛选, 快速确认, 修改答案, 重划区域) -> 
完整性校验与导出 -> 生成 SQLite/JSONL/PNG
```

## 8. 验收标准

1. **核心流程**：离线安装包在干净的 Win10 x64 (AVX2) 环境中可启动，无需联网即可完成题库的提取和校对。
2. **精度指标 (分档验收)**：
   - 原生页：Anchor Recall >= 99%, Answer Exact Match >= 99.5%, Review Rate <= 3%
   - 扫描页：Anchor Recall >= 95%, Answer Exact Match >= 97%, Review Rate <= 15%
   - 必须坚守红线：串题污染率 <= 0.5%，Silent Error Rate <= 0.2%。
3. **性能体验**：5000 题列表虚拟化不卡顿，峰值内存 <= 2GB。原生页单页处理 <= 0.3s，需 OCR 单页 <= 1.5s，混合 300 页 (50% 扫描) <= 8 分钟。
4. **人工保护**：重跑任务绝对不能覆盖已被标记为 `manual_edited=true` 的题目数据。
