# 02. Functional Spec

## 1. PDF 导入与预检
- **功能目标**：初始化解析任务。
- **输入**：题目 PDF 文件，(可选)答案 PDF 文件，RuleProfile。
- **输出**：任务 ID，扫描页占比预估，疑似双栏页数提示，是否加密预警。
- **正常流程**：验证离线模型，扫描 PDF 属性，快速探测文本覆盖率计算 `parse_source`，建立 Job 记录。
- **异常流程**：PDF加密要求输入密码；若缺失本地 OCR 模型则允许降级进入受限模式（扫描页将 failed）。

## 2. 混合解析管线 (Native / OCR)
- **功能目标**：逐页解析获得统一的 `TextBlock` 序列。
- **输入**：单个 PDF 页。
- **正常流程**：基于文本层探测 NativeQualityScore。
  - >= 0.8: 走原生提取。
  - < 0.6: 走 OCR 预处理（灰度化、纠偏、二值化、归一化 DPI）并进行 RapidOCR 推理。
- **异常流程**：OCR 失败或置信度极低，记录 WARNING，状态标记为 uncertain。
- **边界条件**：单页失败转换为 `PAGE_PROCESSING_CRASHED` issue 记录，绝不中断全局任务。

## 3. 题目边界规划与截取
- **功能目标**：精确划定题目和解析的范围，必须包含图中和表中的对象。
- **输入**：TextBlock 列表与正则表达式 (RuleProfile)。
- **正常流程**：
  1. 通过正则匹配提取 Anchor（题号、选项、答案）。
  2. 合并同属一题的文本框 bbox。
  3. 探测 Native PDF 中的 drawing / image 边界，与文本边界做并集。对于扫描页，做连通域检测。
  4. 截取原 PDF 图层，转为 PNG 图片。
  5. 异常流程：如果题号跳跃（45->47），执行局部放宽规则探测，未果报 WARNING；如果非文本对象边界超出下沿，报 `FIGURE_TRUNCATED`。

## 4. 人工 Review 工作台
- **功能目标**：高效率完成题目人工确认与修正。
- **UI 结构**：三栏（题号列表，对照画布，属性编辑区）。
- **正常流程**：
  - 点击左侧题号，中栏并列展示“提取出的图片”和“原 PDF 定位高亮页”。
  - 操作快捷键 (J/K 上下切换，Enter 确认，D 重划区域)。
  - 对有串题、缺失错误的，可以通过重划区域手动框选，生成新的截图。
- **数据契约**：任何修改都会标记该题目 `manual_edited=true`，该标记一旦生效，任何重跑操作均会跳过或强制要求用户二次确认覆盖。

## 5. 导出
- **功能目标**：生成标准化产物。
- **输入**：需导出的状态范围（全部，已确认）。
- **正常流程**：导出 JSONL（包含 config_hash，pipeline_version），SQLite 库和图片 zip 包。导出前做完整性检验。
- **异常流程**：图片缺失或关联主键重复时阻断并报警。
